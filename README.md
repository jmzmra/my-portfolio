# My Music Portfolio

A Spotify-inspired music showcase built with React, Vite, and Tailwind CSS.

This project highlights my favorite:
- Albums
- Songs
- Artists
- Playlists

## Features
- Responsive modern UI
- Album and artist showcases
- Playlist sections
- Smooth animations and transitions
- Clean Tailwind styling

## Built With
- React
- Vite
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
